# Simple Todo App

A simple, interactive to-do list application that helps users organize tasks and keep track of their due dates.

## Functionality

The Simple Todo App allows users to:

- View a list of existing tasks when the application loads.
- Add new tasks using a popup form.
- Assign optional due dates to tasks.
- Mark tasks as completed or incomplete.
- Delete tasks from the list.
- Receive validation messages when entering invalid information.
- Close the popup using the close button or Escape key.

After creating a task, the form automatically resets and disables the Create button until valid information is entered again.

## Technology

This project uses the following technologies and techniques:

- **HTML5:** Provides the application's structure.
- **CSS3:** Styles the interface using the BEM methodology.
- **JavaScript ES6:** Handles user interactions and application functionality.
- **Object-Oriented Programming (OOP):** Organizes functionality into reusable classes.
- **Todo Class:** Creates individual tasks and manages their functionality.
- **FormValidator Class:** Handles input validation and submit button states.
- **UUID Library:** Generates unique identifiers for newly created tasks.
- **DOM Manipulation:** Dynamically adds, updates, and removes tasks.
- **Event Listeners:** Handle form submissions, checkbox changes, and button clicks.
